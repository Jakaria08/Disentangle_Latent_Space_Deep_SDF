# Codex Instructions

Before creating, modifying, moving, deleting, or overwriting any file or folder,
ask the user for explicit permission.

Always show a plan before changing any file or folder.

If the user gives permission to perform a whole task, that permission covers the
file and folder changes needed to complete that approved task.

Reading files, inspecting results, and running non-mutating analysis commands are
allowed without permission unless the user says otherwise.
