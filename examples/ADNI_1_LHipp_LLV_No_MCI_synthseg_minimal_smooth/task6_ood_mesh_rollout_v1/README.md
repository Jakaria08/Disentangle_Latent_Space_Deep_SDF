# OOD mesh rollout

This isolated validation-only experiment starts from representative CN and AD
meshes near age 75 and evaluates both diagnosis conditions through age 105.
It compares one-shot transport with annual recursive composition for the
selected direct-mesh and explicit latent-mesh cocycles.

The generated meshes are stress-test outputs, not calibrated biological
forecasts. Training age support ends near age 96. Test data are not loaded.

Run the script first, then open
`notebooks/ood_age75_to105.ipynb`. See `RUNBOOK.md` for exact commands.
