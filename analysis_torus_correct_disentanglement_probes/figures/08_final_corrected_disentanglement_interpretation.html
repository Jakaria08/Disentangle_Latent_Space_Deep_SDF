How to read the score

The score is not a publication metric by itself. It is a compact diagnostic:

  • Higher disease AUC from raw or predicted disease components is good.
  • Diagnosis AUC far from 0.5 in age or residual components is leakage and is penalized.
  • Oracle-gated disease is excluded from the score because it uses the true disease label.

What this fixes

The previous report used ||v_component|| AUC as if it were disentanglement. That was incomplete. This report trains held-out probes on full vectors, so it can detect information stored in vector direction, not only speed magnitude.

Remaining caveat

Disease and residual networks receive time inputs in the current architectures. Therefore age prediction from disease/residual components is a real leakage diagnostic, but it also reflects the architectural fact that those branches are allowed to be time-dependent. If the goal is strict age-free disease/residual, the architecture or losses must prevent time information from being encoded there.
