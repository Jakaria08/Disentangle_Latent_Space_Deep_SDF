Correct disentanglement protocol

Defines the corrected held-out external-probe protocol and flags oracle-gated disease as non-label-free.

The previous norm-AUC analysis was only a speed diagnostic. This report uses external probes on the full velocity component vectors.

Main test

For each subject, compute instantaneous component velocities at baseline age:

v_age, v_disease, v_residual = flow_components(z0, s=t=baseline_age_norm)

Then train probes on train subjects and evaluate on held-out test subjects.

Desired behavior

  • diagnosis from v_age should fail; AUC near 0.5.
  • diagnosis from v_residual should fail; AUC near 0.5.
  • diagnosis from v_disease_raw should succeed only if the disease branch contains label-free disease information.
  • age from v_age should succeed.
  • age from v_disease_raw and age from v_residual should be low if those branches are age-clean.

Oracle warning: if the true disease label is fed to the model, disease velocity can become zero for healthy subjects by construction. That is not label-free disentanglement.
